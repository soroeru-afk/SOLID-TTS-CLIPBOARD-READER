# SOLID TTS CLIPBOARD READER

インダストリアル・モノトーン仕様のクリップボード音声読み上げ＆アバター口パク連動 PWA アプリケーション。

## 主な機能・特徴

1. **上部スライドアップ方式（Slide-up Drawer）**
   - 狭小ブラウザ枠でも重要操作（読み上げ・再生・停止・タブ切替）を見失わない画面下部固定バー。
   - テキスト入力や詳細設定は、アバターステージへ向かって下から上へスムーズにせり出すドロワー構造。

2. **テキスト入力エリアの自在伸縮・リサイズ**
   - ドロワー最上部の掴みバー（リサイズハンドル）による30%〜94%の無段階高さ調節。
   - 「標準（52%）」と「最大化（92%）」のワンタッチ切替ボタン。
   - ドロワーの高さ連動によるテキストエリアの自動縦長拡大。
   - 操作ボタン（クリア、閉じて再生）の下部常時固定。

3. **ストイックなインダストリアルデザイン**
   - 絵文字・カラーアイコンを廃止し、Lucide Icons による幾何学的モノトーンUIに統一。
   - 1pxソリッドボーダーと精密なグリッドレイアウト。

4. **アバター動画連携（IndexedDB）**
   - 最大3スロットのアバター動画永続保存。
   - 音声合成（TTS）の発声タイミングと完全に同期した口パク動画の自動ループ再生・停止。

5. **各ボイス初期値テーブル＆ワンタッチ初期値リセット**
   - ボイス選択時に各ボイス固有の最適基準値（話速・ピッチ・音量）を自動適用・スロット保存。
     - Microsoft Ichiro: 2.0x / 1.0x / 100%（スロット1標準）
     - Microsoft Haruka: 1.9x / 1.1x / 85%（スロット2標準）
     - Microsoft Sayaka: 1.9x / 1.1x / 85%
     - Microsoft Ayumi: 2.3x / 1.4x / 85%
     - Google 日本語: 1.2x / 1.1x / 85%
   - 音声詳細設定内の「初期値にリセット」ボタンで、いつでも基準値へワンタッチ復元。

6. **読上テキスト履歴のデータ構造と永続化（最大10件管理）**
   - クリップボード読み上げおよび手動入力再生時に自動で履歴スタックへ記録。
   - 重複テキストは最新日時として先頭へ自動再配置、常に直近10件を localStorage（`solid-tts-history-v1`）へ永続保存。
   - 画面最下部の中央に配置された「読上履歴 (件数)」ボタンから下部ドロワーを直感展開。
   - 上部バーによるドラッグ高さ調節、最大化表示、テキスト入力ドロワー内からの「履歴から呼出」に完全対応。
   - 各履歴カードから「もう一度読む」「入力欄にセット」「クリップボードにコピー」「個別削除」「全消去」が可能。
   - BUFFER 10 銘板風バッジ、インデックス（#1〜#10）、種別（CLIPBOARD / MANUAL）、文字数、タイムスタンプを等幅フォントで整然配置したインダストリアル調デザイン。

7. **PWA & スタンドアローン対応**
   - Web App Manifest および Service Worker によるオフラインキャッシュ＆高速起動。
   - アプリ単体ウィンドウ（Chrome App Mode / PWA）での快適な常駐稼働。
